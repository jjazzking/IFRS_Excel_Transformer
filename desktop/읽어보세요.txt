기준서 데스크 — 여는 방법
=========================

설치할 것도, 받을 것도 없습니다. 이 폴더를 통째로 푼 다음:

  [1] 실행.bat 을 두 번 누릅니다.

  [2] 검은 창이 하나 뜨고, 잠시 뒤 브라우저가 열립니다.
      안 열리면 검은 창에 적힌 주소를 복사해서 브라우저에 붙여넣습니다.

  [3] 다 쓴 뒤에는 검은 창에서 Ctrl+C 를 누르거나 창을 닫습니다.

실행.bat 이 막혀 있다면, 명령 프롬프트에서:

    cd /d "이 폴더 경로"
    python 실행.py


무엇이 필요한가
---------------
파이썬 3.7 이상. 그게 전부입니다.
추가로 설치하는 꾸러미(pip install)는 없습니다.


파일이 어디로 가나
------------------
아무 데도 가지 않습니다.

  · 주소가 127.0.0.1 로 시작합니다. 내 컴퓨터 안에서만 열리는 주소이고,
    같은 사무실의 다른 컴퓨터에서는 열 수 없습니다.
  · 의사록 PDF 는 브라우저 안에서 읽습니다. 어디로도 올라가지 않습니다.
  · 스캔 페이지를 읽는 OCR 도 브라우저 안에서 돕니다.
  · 인터넷이 끊겨 있어도 똑같이 됩니다. 한번 확인해 보셔도 좋습니다.


잘 안 될 때
-----------
· 검은 창에 "화면 파일(dist)을 못 찾았다" → 압축을 풀 때 일부만 풀린 경우입니다.
  실행.py 옆에 dist 폴더가 있어야 합니다.

· 브라우저는 열렸는데 화면이 하얗다 → 검은 창을 그대로 두고 F5 로 새로 고칩니다.

· 회사 백신이 막는다 → 검은 창의 주소를 직접 브라우저에 붙여넣어 봅니다.
