# 주가 작업대 — 계획과 자료 출처

## 자료 출처 — 금융위원회 주식시세정보 V2 (공공데이터포털)

```
GET https://apis.data.go.kr/1160100/GetStockSecuritiesInfoService_V2/getStockPriceInfo_V2
    ?serviceKey=…&resultType=json&numOfRows=1000&pageNo=1
    &beginBasDt=YYYYMMDD&endBasDt=YYYYMMDD(미만)
    &likeSrtnCd=005930 | itmsNm=삼성전자 | likeItmsNm=삼성
```

- 옛 주소(`/1160100/service/GetStockSecuritiesInfoService/getStockPriceInfo`)는 V2 키로 부르면
  "등록되지 않은 서비스키"(V1 기준), End Point 만 부르면 "서비스 없음"이 난다.
- 브라우저에서 바로 불린다 (CORS 허용, 2026-10-19 배포 사이트에서 확인).
- 응답 필드: `basDt` 기준일 · `srtnCd` 단축코드 · `isinCd` · `itmsNm` 종목명 · `mrktCtg` 시장 ·
  `clpr` 종가 · `vs` 대비 · `fltRt` 등락률 · `mkp` 시가 · `hipr` 고가 · `lopr` 저가 · `trqu` 거래량 ·
  `trPrc` 거래대금 · `lstgStCnt` 상장주식수 · `mrktTotAmt` 시가총액
- 다음 영업일 오후에 반영된다 (2026-10-19 월요일 조회 시 최신 2026-10-16).
- 값은 실제 종가이고 수정주가가 아니다.
- 키는 도메인에 묶이지 않는다. 배포 결과물에 들어가므로 하루 호출 한도(개발계정 1만 건)를 남이 쓸 수 있다.

## 용도별로 고르기 (이자율 작업대처럼)

용도 → 기준일·기간 → 종목 순으로 좁힌다. 용도를 고르면 근거 문단과 주의점을 안내한다.
종목은 엑셀에서 회사 이름 열을 그대로 붙인다. 줄마다 검색 이름·종목명·코드를 옆에 보여 주고,
`(주)`·`㈜`·`주식회사` 는 떼고 찾는다. 이름이 일부만 맞거나 후보가 여럿이면 노랗게, 못 찾으면 빨갛게.

| 용도 | 근거 | 뽑는 값 |
| --- | --- | --- |
| 기말 공정가치 | 1113 76·77·80 | 기준일 종가 (휴장일이면 직전 거래일) |
| 주식보상 | 1102 16·17·30·47 | 측정기준일까지 과거 N년 일별 종가 (변동성 계산은 엑셀에서) |
| EPS 주석 | 1033 19~21·26·64, 45·46, A4·A5 | 기본값: 상장주식수 변동표(기초·변동일·증감·일수·일수 가중평균) — 회사의 가중평균유통보통주식수 대사용. 선택: 회계기간 월별·기간 평균시장가격(희석 EPS) |
| 손상징후 | 1036 12 | 기준일 종가 · 상장주식수 · 시가총액 |
| 기준주가 | 자본시장법령 · 증권발행공시규정 | 기산일 기준 1개월·1주·최근일 거래량 가중평균과 산술평균 (거래대금÷거래량 또는 종가×거래량) |

기준주가의 1개월은 기산일 한 달 전 같은 날의 다음 날부터, 1주는 7일 전의 다음 날부터 기산일까지.
규정마다 기산일·기간이 다르므로 화면에서 원문 확인을 안내한다.

## 아이디어 — 지금은 만들지 않음

- **보유수량 × 종가 = 평가금액·평가손익**: 조서의 종목·수량(·장부가) 열을 붙여넣으면 공정가치와 평가손익
  열을 붙여 준다. 회사 보유 내역을 다루는 일이라 보안상 보류 (저장소 주인 결정, 2026-10-19).
- **기대변동성 계산**: 일별 종가의 로그수익률 표준편차 × √연간거래일수. 지금은 일별 종가만 뽑는다 (저장소 주인 결정).
- **OpenDART 로 자기주식·발행주식 총수 붙이기**: `stockTotqySttus`(주식의 총수 현황 — 발행주식총수·자기주식수·유통주식수,
  분기·반기·사업보고서 기준), `tesstkAcqsDspsSttus`(자기주식 취득·처분), `irdsSttus`(증자·감자 현황). 종목코드 → 고유번호
  (`corpCode.xml`, zip) 매핑이 필요하다. 브라우저 직접 호출(CORS) 가능 여부 확인 중.
- **당기말·전기말 나란히**: 기준일 여러 개 × 종목 비교표 (환율 작업대 비교표 모양).
