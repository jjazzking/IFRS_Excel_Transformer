# 기능 작명 — 이름 하나로 무엇을 하는 도구인지 알게 하기

## 지금 이름의 문제

현재 이름은 **"회계기준서 조서 추출기"** 다. 세 가지가 걸린다.

1. **"추출"은 만든 사람의 말이다.** 사용자가 하는 일은 기준서를 *찾아서*, *읽고*,
   *골라 담아*, 조서에 *붙여넣는* 것이다. 어디에서도 무언가를 추출하지 않는다.
   화면 안에서도 말이 갈린다 — 버튼은 `담기`, 패널은 `조서 추출 대기 목록`,
   파일명은 `_조서추출.xlsx`, VBA 안내문은 `웹 추출기에서`. 같은 것을 세 이름으로 부른다.
2. **이름이 기능을 가둔다.** 확장 방향(인용 검증, 개정 추적, 공시 체크리스트)은
   조서 추출이 아니다. "추출기"라는 이름으로는 그 기능들이 이 도구에 붙을 이유를
   설명하기 어렵다.
3. **입에 붙지 않는다.** 현장에서 "그 추출기 있잖아"로 불리면 다음 사람에게 전달되지 않는다.

## 제안

### 제품 이름: **기준서 데스크 (Standards Desk)**

기준서를 놓고 하는 모든 작업이 올라오는 책상. 오늘은 찾기·인용이지만, 검증·개정 추적·
체크리스트가 붙어도 이름을 바꿀 필요가 없다. 사내에서 "기준서 데스크에서 뽑았어요"처럼
쓰인다.

| 후보 | 장점 | 단점 |
| --- | --- | --- |
| **기준서 데스크** (추천) | 확장해도 이름이 버틴다, 부르기 쉽다 | 오늘 무엇을 하는 도구인지 이름만으로는 덜 구체적 |
| 조서 인용기 | 지금 하는 일이 정확히 담긴다 ('인용'은 실무 용어) | 검증·개정 추적이 붙으면 이름을 다시 바꿔야 한다 |
| 기준서 클립 | 담아서 붙인다는 동작이 그대로 | 가벼워 보이고, 확장 여지가 좁다 |

이름은 TFT에서 정하되, **결정 전이라도 화면 안의 용어는 먼저 통일하기를 제안한다.**
아래 표는 이름 결정과 무관하게 바로 적용할 수 있다.

### 화면 용어 통일 — 하나의 은유로

**찾는다 → 읽는다 → 담는다 → 붙여넣는다.** 네 동사 밖으로 나가지 않는다.

| 위치 | 현행 | 제안 | 이유 |
| --- | --- | --- | --- |
| 앱 제목 (`index.html`) | 회계기준서 조서 추출기 | 기준서 데스크 | 제품 이름 |
| 우측 패널 (`SelectedList.tsx`) | 조서 추출 대기 목록 | **인용함** | '대기 목록'은 무언가를 기다리게 한다. 담긴 것이 보이는 곳이다 |
| 본문 버튼 (`StandardReader.tsx`) | 담기 / 조서에 담기 | **담기** | 한 동작에 한 이름 |
| 복사 버튼 (`SelectedList.tsx`) | 엑셀 서식 복사 (음영/테두리) | **조서에 붙여넣기 (서식 유지)** | 사용자가 다음에 할 일을 버튼에 적는다 |
| 복사 버튼 | 순수 텍스트 복사 | **텍스트만 복사** | '순수'가 무엇과 대비되는지 알 수 없다 |
| 내보내기 파일명 | `..._조서추출.xlsx` | `..._기준서인용.xlsx` | 파일을 받은 사람이 내용을 안다 |
| VBA 안내문 (`VbaSnippetModal.tsx`) | 웹 추출기에서 먼저 복사해주세요 | 기준서 데스크에서 먼저 복사해주세요 | 제품 이름으로 부른다 |
| 3존 안내 | (없음) | 좌 **찾기** · 중 **읽기** · 우 **담기** | 처음 여는 사람이 화면 구조를 3초에 이해한다 |

### 확장 기능 이름 미리 잡아두기

나중에 붙일 때 이름이 겹치지 않도록 지금 예약해 둔다 (`docs/roadmap.md` 참조).

| 기능 | 이름 | 한 줄 설명 |
| --- | --- | --- |
| 조서의 인용문을 현행 기준서와 대조 | **인용 점검** | 이미 쓴 조서가 지금 기준서와 맞는지 본다 |
| 판본 간 문단 비교 | **개정 추적** | 무엇이 바뀌었고 어느 조서가 영향받는지 본다 |
| 공시요구 문단 모으기 | **공시 체크리스트** | 기준서가 요구하는 공시를 표로 뽑는다 |

## 작명 원칙 (앞으로 기능이 붙을 때 이 기준으로)

1. **사용자의 동사로 짓는다.** 시스템이 하는 일(추출·파싱·렌더)이 아니라 사람이 하는 일.
2. **한 개념에 한 단어.** 담기/선택/추가를 섞지 않는다.
3. **버튼에는 다음에 일어날 일을 적는다.** "복사"보다 "조서에 붙여넣기".
4. **실무 용어를 이긴다고 생각하지 않는다.** 인용·조서·footing 처럼 현장에서 쓰는 말을 그대로.
