# 기준서 footing 계획 — 자동 1차 검증 + 사람 표본 확인

## 왜 계획이 필요한가

지금 상태로 "40개 기준서를 4명이 나눠 본다"고 하면, 1인당 900문단 남짓을 원문과 대조하는
일이 된다. 9/15까지 끝날 일이 아니고, 끝났다고 해도 무엇을 어디까지 봤는지 남지 않는다.

그래서 순서를 바꾼다. **기계가 걸러낼 수 있는 결함을 먼저 전수로 걸러내고, 사람은 기계가
판정할 수 없는 지점만 본다.** 판정과 수정은 여전히 사람이 한다 — 자동 검증은 볼 곳을
좁힐 뿐이다.

## 자동 1차 검증 (`scripts/audit_standards.py`)

```bash
python3 scripts/audit_standards.py                      # 요약
python3 scripts/audit_standards.py --csv footing.csv    # 검수 워크시트(엑셀에서 바로 열림)
python3 scripts/audit_standards.py --assign 4           # 검수자 4명에게 기준서 배분
```

### 현재 DB(기준서 40건 / 문단 3,661건) 검사 결과

| 규칙 | 심각도 | 건수 | 무엇을 의심하는가 |
| --- | --- | ---: | --- |
| `NUM_GAP` | P1 | 6개 기준서 | 본문 문단번호가 중간에 비어 있음 (파싱 누락 또는 삭제문단 미표기) |
| `HEADING_LEAK` | P2 | 208 | 마지막 줄이 본문이 아니라 다음 절의 제목으로 보임 |
| `OVERSIZE` | P2 | 18 | 2,500자 초과 — 여러 문단이 하나로 붙었을 가능성 |
| `TAIL_NOISE` | P2 | 1 | 마지막 줄이 쪽번호 등 본문이 아닌 흔적 |
| `NO_TERMINAL` | P3 | 421 | 문장이 종결부호 없이 끝남 |
| `NO_SECTION` | P3 | 9 | 문단제목이 없어 조서에 제목 행을 넣을 수 없음 |

**P1·P2 합계 230곳 — 전체 문단의 6.3%.** 4명이 나누면 1인당 45~85곳이고, 한 곳당
원문 대조에 2분을 잡아도 1인 2~3시간이면 끝난다. 3,661문단 전수 대조와는 다른 일이 된다.

### 자동 검증이 이미 찾아낸 실제 결함

- **제1032호 문단 5·6·7 누락** — 문단 4 다음이 곧바로 8이다. 파서가 놓쳤다.
- **제1032호 문단 100 (10,238자)** — `[…삭제함]` 뒤에 부록 적용지침(AG1~) 전체가 한
  문단으로 딸려 붙었다. 이 상태로 조서에 담으면 200행이 쏟아진다.
- **제1116호 문단 2** — 본문 끝에 다음 절 제목 `적용` 이 붙어 있다.
- **제1007호 문단 52** — 끝줄이 `시행일고과 경과 규정` 으로, 제목이 깨진 채 섞였다.

이 넷은 사람이 40개를 다 읽어야 나오는 종류의 결함인데, 스크립트가 몇 초 만에 짚었다.
반대로 `HEADING_LEAK` 208건 중에는 정상인 것도 섞여 있다 — 그래서 사람이 본다.

## 사람 2차 검수 절차

1. `--csv` 로 워크시트를 만든다. 열은 `심각도 / 기준서 / 문단 / 규칙 / 검출근거 /
   판정 / 수정내용 / 검수자` 이고, 뒤 세 칸을 검수자가 채운다.
2. 각자 배정된 기준서의 P1·P2 행을 원문(HWP 또는 회계기준원 공시본)과 대조해
   **정상 / 오류** 만 판정한다. 오류면 무엇이 잘못됐는지 한 줄로 적는다.
3. 배정된 기준서마다 **P1·P2에 걸리지 않은 문단 5개를 무작위로 골라** 함께 대조한다
   (기준서당 5개 × 40 = 200문단). 자동 검증이 놓치는 결함이 있는지 보는 표본이다.
4. 판정이 끝난 워크시트를 모으면, 수정은 파서(`scripts/parse_kifrs_hwp.py`)를 고쳐
   재파싱하는 것이 원칙이다. JSON 직접 수정은 재파싱 때 되돌아가므로 최후 수단으로만 쓴다.
5. 재파싱 후 `audit_standards.py` 를 다시 돌려 P1이 0이 되는지 확인한다.

## 배포 판정 기준

| 등급 | 기준 |
| --- | --- |
| 배포 가능 | P1 0건 · P2 판정 완료 · 표본 200문단에서 신규 결함 0건 |
| 조건부 배포 | P1 0건 · P2 미판정 20건 이하 (해당 기준서에 배너 표시) |
| 배포 보류 | P1 잔존 또는 표본에서 신규 결함 발견 |

## 아직 남은 것

- **제1109호 '금융상품' 미반영.** 다단계 문단번호 대응 후 재파싱이 필요하다. 금융상품은
  기말감사에서 인용 빈도가 높아, v1(10/11) 전까지는 들어가야 한다.
- **원문 대조 기준.** 검수자마다 다른 판본을 보면 판정이 갈린다. 대조 기준 판본을
  하나로 정하고 워크시트에 적어 둔다.
- **기준서 원문의 사내 재배포 범위.** 회계기준원 저작물을 사내 도구에 담아 배포하는 것에
  대해 법인 차원의 확인이 필요하다 — 배포 결정 전에 짚어야 할 항목이다.
